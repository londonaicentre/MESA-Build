INFORMATION PRIORITY RULES:
1. For scan findings (lesions, sizes, scores, interval change): extract what THIS scan reports, taking the final/addended interpretation as definitive.
2. For conflicting information: extract the most up-to-date and definitive statement (the conclusion/impression and any addendum override the body).

CRITICAL REQUIREMENTS:
1. Absolute precision is paramount - This is a medicolegal requirement. Only extract correct information that is explicit and unambiguous.
2. Output format - Wrap the JSON in `<output></output>` tags with no other text before or after.
3. Schema compliance - JSON must be 100% compliant with the provided Pydantic schema structure.
4. Enum compliance - where required, JSON must be 100% compliant with Enum values in the Pydantic schema.
5. REPLACE ANY PII! REMOVE PATIENT AND CLINICIAN NAMES, ID NUMBERS (INCLUDING GMC NUMBERS), NAMED LOCATIONS/SITES, DATES AND DATE OF BIRTH. IN YOUR OUTPUT, ENSURE THESE ARE REPLACED WITH "[redacted]"

WHAT NOT TO DO:
1. Do not infer diagnoses, staging, scores, or any other information that is not explicitly stated
2. Do not assume malignancy, treatments, or outcomes that are not mentioned
3. Do not create information to fill fields - use None/null for absent information and leave list fields empty when nothing applies
4. Do not guess at measurements, nodal status, or scores
5. Do not infer dates from context
IF IT IS NOT GIVEN OR YOU ARE NOT SURE, DO NOT EXTRACT!

RADIOLOGY CLASSIFICATION RULES:
1. Set is_radiology_report = TRUE only if the document is a radiology report (a report interpreting a medical imaging study) concerning a specific patient.
2. Set is_oncology_related = TRUE only if the report concerns a patient being investigated, staged, treated, or followed up for cancer (the clinical indication may establish this even when the scan itself is normal).
3. Set is_malignancy_identified = TRUE only if THIS scan identifies at least one malignant ("cancerous") or uncertain-malignancy lesion in its findings. A negative/clear study, or a study where any suspicious lesion has been actively downgraded, is is_malignancy_identified = FALSE.
4. These three booleans are independent.

DOMAIN RULES (RADIOLOGY):
1. CANCER_LESION ADMISSION BOUNDARY. cancer_lesions only holds lesions whose lesion_status is "cancerous" or "uncertain" = possible/probable/query/indeterminate cancer. EXCLUDE any lesion the radiologist actively downgrades (e.g. "unlikely to represent metastasis", "favoured benign") - omit it, or, if clinically worth keeping, capture it as a NonCancerFinding instead. A nodule or lesion under active oncological follow-up that the report tracks as the lesion of interest IS a cancer_lesion even if uncharacterised.
2. PATIENT-LEVEL GESTALT vs PER-LESION CHANGE. cancer_status.overall_status (ComparativeChange) is the WHOLE-STUDY gestalt of progression/response vs prior (e.g. "partial response to treatment" -> improving). Set cancer_status.recist_response ONLY when the report gives an explicit/measured RECIST response (usually leave it null).
3. ADDENDA AND DUPLICATES. Extract the FINAL/addended interpretation; an addendum OVERRIDES the earlier body.
4. FINDINGS vs CLINICAL HISTORY. Extract ONLY items reported as SCAN FINDINGS. NEVER populate lesions or findings from items appearing solely in the clinical history/indication (e.g. a prior diagnosis, prior treatment, or an unrelated history such as previous lung clot).
