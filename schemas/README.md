# mesa-build/schemas

Domain specified schemas

## Creating a new schema

### Prerequisties

- Linux/Mac
- [uv](https://docs.astral.sh/uv/)

### Quickstart

1. Create a new schema boilerplate directory: `uvx copier copy _schema <new schema name> --trust`.

2. Answer the questions posed.

3. Run `make` in the new schema directory created to check the boilerplate.

4. Add custom content to each file.
